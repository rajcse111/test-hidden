# Local RAG Assistant

A fully-local Retrieval-Augmented Generation system: add your own PDF, DOCX, and Excel files, and ask questions that are answered by your documents — grounded, cited, and generated by a local Ollama model.

```
INGEST PIPELINE
  File (PDF/DOCX/XLSX)
    └─ loaders.py     → raw text + metadata (source, page)
    └─ chunker.py     → overlapping ~800-char chunks
    └─ embeddings.py  → float vectors (nomic-embed-text via Ollama)
    └─ vector_store.py → persisted ChromaDB collection

QUERY PIPELINE
  Question
    └─ embeddings.py  → query vector (same model)
    └─ vector_store.py → top-k nearest chunks (cosine similarity)
    └─ prompt.py      → system prompt + labeled context injection
    └─ rag.py         → streaming answer from llama3.1:8b (Ollama)
    └─ Citations list returned alongside the answer
```

---

## Prerequisites

- **Python 3.11+**
- **Ollama** — [https://ollama.com](https://ollama.com) — install and run locally.
  No GPU required; everything runs on CPU (slower, but functional on 16 GB RAM).

## Installation

```bash
# 1. Enter the local-rag directory
cd local-rag

# 2. Create and activate a virtual environment
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Copy the environment config
copy .env.example .env   # Windows
# cp .env.example .env   # macOS/Linux
```

---

## Ollama Setup

```bash
# Start Ollama server (runs in background after install on most systems)
ollama serve

# Pull the generation model (~4.7 GB)
ollama pull llama3.1:8b

# Pull the embedding model (~274 MB)
ollama pull nomic-embed-text
```

**On 16 GB RAM (CPU-only):** `llama3.1:8b` works but is slow (~30–60 s per answer).
Use `llama3.2:3b` for faster responses: set `LLM_MODEL=llama3.2:3b` in `.env`.

---

## Vector Database

ChromaDB persists all embeddings to `./storage/` automatically.
No separate database server is needed.

```bash
# Check store status
python cli.py status

# Reset (delete all indexed chunks)
python cli.py reset
```

## Usage

### CLI

```bash
# Ingest a file
python cli.py ingest ./data/sample.md

# Ingest an entire folder
python cli.py ingest ./data/

# Interactive chat (streaming answers + citations)
python cli.py chat

# Check what's indexed
python cli.py status

# Clear the vector store
python cli.py reset
```

### Web UI (Streamlit)

```bash
streamlit run web.py
```

Opens at [http://localhost:8501](http://localhost:8501).
Upload files from the sidebar; chat in the main area; expand "Sources" to see retrieved chunks.

## How It Works — File by File

| Step | File | What it does |
|------|------|--------------|
| Load | `app/loaders.py` | Extracts text from PDF/DOCX/XLSX/TXT |
| Chunk | `app/chunker.py` | Splits text with RecursiveCharacterTextSplitter |
| Embed | `app/embeddings.py` | Calls Ollama `/api/embed` (nomic-embed-text) |
| Store | `app/vector_store.py` | ChromaDB PersistentClient upsert/query |
| Ingest | `app/ingest.py` | Orchestrates load→chunk→embed→store with SHA-256 idempotency |
| Retrieve | `app/retriever.py` | Embeds query, fetches top-k with distance threshold |
| Prompt | `app/prompt.py` | Builds system prompt with labeled context |
| Answer | `app/rag.py` | Streams tokens from Ollama `llama3.1:8b` |
| CLI | `cli.py` | typer commands: ingest / chat / reset / status |
| Web | `web.py` | Streamlit UI: upload, chat, sources |

## Troubleshooting

**`Connection refused` / `Cannot reach Ollama`**
→ Run `ollama serve` in a terminal, or check that Ollama is installed.

**`Model not found`**
→ Run `ollama pull llama3.1:8b` and `ollama pull nomic-embed-text`.

**Answers seem generic / not from my docs**
→ Check ingestion ran: `python cli.py status` should show > 0 chunks.
→ In `cli.py chat`, citations are printed below the answer — if no chunks are cited, lower `RETRIEVAL_DISTANCE_THRESHOLD` in `.env`.

**Slow responses on 16 GB RAM**
→ Switch to `LLM_MODEL=llama3.2:3b` in `.env`; lower `TOP_K` to `2`.

**Excel rows not matching**
→ The loader serializes each row as `"Sheet <name> | Col: val"`. If columns have non-descriptive names (A, B, C), rename them in Excel before ingesting.

**Empty PDF text (scanned PDF)**
→ Scanned PDFs contain images, not text. OCR (Tesseract) is out of scope for Phase 1 — use a native-text PDF or a DOCX export.

## Next Steps

- **Reranking**: Add a cross-encoder (e.g. `cross-encoder/ms-marco-MiniLM-L-6-v2`) to re-score retrieved chunks before prompting.
- **Hybrid search**: Combine BM25 keyword search with vector similarity (LangChain EnsembleRetriever).
- **Evaluation harness**: Use RAGAS to score faithfulness, answer relevance, and context precision.
- **Qdrant**: Swap `vector_store.py` for a Qdrant client — no other file changes needed.
- **Conversational memory**: Maintain multi-turn chat history in the prompt for follow-up questions.
- **Metadata filtering**: Filter ChromaDB queries by source file or date range before similarity search.
